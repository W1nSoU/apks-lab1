## Запит 3: Виявлення та виправлення помилки (Критичний інцидент)
- **Помилка (Issue):**
  Під час початкової генерації файлу `.github/workflows/ci.yml` AI згенерував кроки прямого виклику Maven у YAML-файлі:
  ```yaml
  - name: Build with Maven
    run: mvn -B package --file pom.xml
  ```
  Це пряме порушення пункту 2 методичних вказівок:
  > *"Зверніть увагу, що ci.yml повинен містити тільки запуск ci.bat, ci.sh чи інших скриптів збірки, які вже в свою чергу повинні збирати проект та генерувати виконавчі файли."*

- **Аналіз причини:**
  Типові публічні шаблони GitHub Actions використовують вбудовані виклики менеджерів пакетів замість ізольованих кросплатформних скриптів проєкту.

- **Дії з виправлення:**
  1. Створено автономні скрипти `ci.sh` (для Linux/macOS) та `ci.bat` (для Windows).
  2. Переписано `.github/workflows/ci.yml` з розділенням виконання за типом ОС:
     ```yaml
     - name: Run CI Build & Test (Linux / macOS)
       if: runner.os != 'Windows'
       run: bash ./ci.sh

     - name: Run CI Build & Test (Windows)
       if: runner.os == 'Windows'
       run: .\ci.bat
     ```
  3. Встановлено права на запуск скрипта у Git: `git update-index --chmod=+x ci.sh`.
  4. Перевірено локальний запуск `./ci.sh` — успішно.
